# Spend Token v2 holder-binding fixture

This directory contains deterministic public conformance material copied from
`crinkl-protocol` commit
`b81ca8258d50feab607aab7f602967aa9f8a4407`.

The fixture tests independent verification of the adopted
`SpendAttestationTokenV2`, `SpendHolderChallengeV2`, and
`SpendHolderControlProofV2` contracts. The private-key seeds are public test
material only. They are not production credentials and make no production
readiness or deployment claim.

The copied vector must remain byte-identical to:

`conformance/v2/vectors/token.spendAttestation.holderBinding.v2.json`
